# Course Material Companion

The original course PDFs are kept in the student's local `Fundamentals of Machine Learning` folder. They are not redistributed with this GitHub project. This short index shows the course topics used to guide the project.

## Topics used

- **Unit 1 — Fundamentals of AI and ML:** the ML life cycle, data types, EDA, missing values, outliers, skewness, and kurtosis.
- **Unit 2 — Automated EDA and Simple Linear Regression:** Pandas and NumPy, profiling reports, correlation, the line equation, residuals, RSS, and R².
- **Unit 3 — Understanding Machine Learning:** supervised and unsupervised learning, regression and classification, features and labels, train/test data, overfitting, underfitting, MAE, and MSE.
- **Unit 4 — Supervised Learning Algorithms:** Linear Regression, model evaluation, Ridge (L2), Lasso (L1), cross-validation, and classification concepts.

The project applies the regression topics to predict State of Health (SoH, %). For beginner-friendly explanations and the results from the supplied CSV, read [`../LEARNING_GUIDE.md`](../LEARNING_GUIDE.md).
